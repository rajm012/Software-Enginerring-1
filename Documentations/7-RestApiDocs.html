Authentication APIs
POST /api/auth/register Register new user account

Description: Creates a new user account with email and password.

Request Body:
{
  "name": "John Doe",
  "email": "john@example.com",
  "password": "securepass123",
  "location": "Mumbai"
}
Parameters:
Parameter Type Required Description
name string REQUIRED Full name of the user
email string REQUIRED Valid email address (unique)
password string REQUIRED Password (min 6 characters)
location string OPTIONAL User's city/location
Success Response (200):
{
  "message": "User registered successfully",
  "user_id": 1
}
Error Response (400):
{
  "error": "Email already registered"
}
POST /api/auth/register-admin Register admin account

Description: Creates a new admin account with referral code verification.

Request Body:
{
  "name": "Admin User",
  "email": "admin@example.com",
  "password": "adminpass123",
  "location": "Delhi",
  "referral_code": "AllIsGood"
}
Parameters:
Parameter Type Required Description
name string REQUIRED Full name of the admin
email string REQUIRED Valid email address (unique)
password string REQUIRED Password (min 6 characters)
location string OPTIONAL Admin's city/location
referral_code string REQUIRED Admin referral code (from .env)
Success Response (200):
{
  "message": "Admin registered successfully",
  "user_id": 2
}
POST /api/auth/login User/Admin login

Description: Authenticates user and creates a session.

Request Body:
{
  "email": "john@example.com",
  "password": "securepass123"
}
Success Response (200):
{
  "message": "Login successful",
  "role": "user",
  "name": "John Doe"
}
Error Response (401):
{
  "error": "Invalid credentials"
}
POST /api/auth/logout AUTH REQUIRED Logout user

Description: Ends user session and logs out.

Success Response (200):
{
  "message": "Logged out successfully"
}
POST /api/auth/forgot-password Request password reset OTP

Description: Sends a 6-digit OTP to user's email for password reset.

Request Body:
{
  "email": "john@example.com"
}
Success Response (200):
{
  "message": "OTP sent to your email"
}
Error Response (404):
{
  "error": "Email not found"
}
POST /api/auth/verify-otp Verify OTP code

Description: Verifies the 6-digit OTP sent to email (valid for 10 minutes).

Request Body:
{
  "email": "john@example.com",
  "otp": "123456"
}
Success Response (200):
{
  "message": "OTP verified successfully"
}
Error Response (400):
{
  "error": "Invalid or expired OTP"
}
POST /api/auth/reset-password Reset password after OTP verification

Description: Sets new password after successful OTP verification.

Request Body:
{
  "email": "john@example.com",
  "new_password": "newsecurepass456"
}
Success Response (200):
{
  "message": "Password reset successfully"
}
POST /api/auth/update-location AUTH REQUIRED Update user's location

Description: Updates the logged-in user's location.

Request Body:
{
  "location": "Bangalore"
}
Success Response (200):
{
  "message": "Location updated successfully"
}
Alert Management APIs
GET /api/alerts AUTH REQUIRED Get alerts for user's location

Description: Retrieves all alerts for the user's registered location with optional filtering.

Query Parameters (Optional):
Parameter Type Description Example
severity string Filter by severity level CRITICAL, HIGH, MEDIUM, LOW
status string Filter by alert status PENDING, VERIFIED, SENT
Example Request:
GET /api/alerts?severity=CRITICAL&status=SENT
Success Response (200):
{
  "alerts": [
    {
      "id": 1,
      "disaster_type": "Flood",
      "location": "Mumbai",
      "severity": "CRITICAL",
      "description": "Heavy rainfall expected...",
      "status": "SENT",
      "scheduled_date": "2026-01-25 14:00:00",
      "created_at": "2026-01-24 10:00:00"
    }
  ]
}
POST /api/alerts/create ADMIN ONLY Create new disaster alert

Description: Creates a new disaster alert (admin only).

Request Body:
{
  "disaster_type": "Cyclone",
  "location": "Chennai",
  "severity": "HIGH",
  "description": "Cyclone expected to make landfall on Jan 26",
  "scheduled_date": "2026-01-26 18:00:00"
}
Parameters:
Parameter Type Required Description
disaster_type string REQUIRED Type of disaster (Flood, Cyclone, etc.)
location string REQUIRED Affected city/location
severity string REQUIRED CRITICAL, HIGH, MEDIUM, or LOW
description string REQUIRED Detailed alert description (min 10 chars)
scheduled_date datetime OPTIONAL Expected disaster time (YYYY-MM-DD HH:MM:SS)
Success Response (201):
{
  "message": "Alert created successfully",
  "alert_id": 15
}
POST /api/alerts/verify/:id ADMIN ONLY Verify pending alert

Description: Changes alert status from PENDING to VERIFIED.

URL Parameters:
Parameter Type Description
id integer Alert ID to verify
Example Request:
POST /api/alerts/verify/15
Success Response (200):
{
  "message": "Alert verified successfully"
}
POST /api/alerts/dispatch/:id ADMIN ONLY Dispatch verified alert

Description: Sends alert to all users in affected location via email.

URL Parameters:
Parameter Type Description
id integer Alert ID to dispatch
Example Request:
POST /api/alerts/dispatch/15
Success Response (200):
{
  "message": "Alert dispatched successfully",
  "emails_sent": 125
}
Data Retrieval APIs
GET /api/cities Get list of Indian cities

Description: Returns list of 50 Indian cities supported by the system.

Success Response (200):
{
  "cities": [
    "Mumbai",
    "Delhi",
    "Bangalore",
    "Hyderabad",
    "Chennai",
    ...
  ]
}
GET /api/users/all ADMIN ONLY Get all registered users

Description: Returns list of all registered users with their details (admin only).

Success Response (200):
{
  "users": [
    {
      "id": 1,
      "name": "John Doe",
      "email": "john@example.com",
      "location": "Mumbai",
      "role": "user",
      "created_at": "2026-01-20 10:30:00"
    }
  ]
}
HTTP Status Codes
Code Status Description
200 OK Request successful
201 Created Resource created successfully
400 Bad Request Invalid request data
401 Unauthorized Authentication required or failed
403 Forbidden Insufficient permissions (not admin)
404 Not Found Resource not found
500 Internal Server Error Server error
Error Handling

All error responses follow a consistent format:

{
  "error": "Error message describing what went wrong"
}
Common Error Messages:
Error Message Cause Solution
Email already registered Email exists in database Use different email or login
Invalid credentials Wrong email or password Check credentials or reset password
Invalid or expired OTP OTP incorrect or older than 10 mins Request new OTP
Unauthorized Not logged in Login first
Admin access required Non-admin user trying admin endpoint Login with admin account
